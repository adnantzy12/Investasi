┌──────────────────────────────────────────────────────────────────────┐
│  STEP 1: INSTALL & JALANKAN                                          │
└──────────────────────────────────────────────────────────────────────┘

Buka terminal/command prompt, lalu ketik:

    npm install

Tunggu sampai selesai, lalu jalankan:

    npm start

Atau pakai script otomatis:

    chmod +x start.sh
    ./start.sh

✅ Kalau berhasil, akan muncul:
   🚀 Server running on http://localhost:3000
   📱 Initializing WhatsApp Bot...


┌──────────────────────────────────────────────────────────────────────┐
│  STEP 2: BUKA HALAMAN ADMIN BOT                                      │
└──────────────────────────────────────────────────────────────────────┘

Buka browser (Chrome/Firefox/Edge), ketik di address bar:

    http://localhost:3000/bot-admin.html

Tunggu beberapa detik...

✅ QR Code akan muncul di layar!


┌──────────────────────────────────────────────────────────────────────┐
│  STEP 3: SCAN QR CODE DARI WHATSAPP                                  │
└──────────────────────────────────────────────────────────────────────┘

📱 DI ANDROID:
   1. Buka WhatsApp
   2. Tap titik tiga (⋮) di pojok kanan atas
   3. Pilih "Linked Devices" (Perangkat Tertaut)
   4. Tap "Link a Device" (Tautkan Perangkat)
   5. Scan QR Code di layar komputer

📱 DI IPHONE:
   1. Buka WhatsApp
   2. Tap "Settings" di pojok kanan bawah
   3. Tap "Linked Devices" (Perangkat Tertaut)
   4. Tap "Link a Device" (Tautkan Perangkat)
   5. Scan QR Code di layar komputer

✅ Kalau berhasil:
   • Status badge jadi 🟢 Terhubung
   • Muncul centang hijau besar ✅
   • Pesan: "Bot Terhubung!"


┌──────────────────────────────────────────────────────────────────────┐

└──────────────────────────────────────────────────────────────────────┘

    6️⃣ /withdraw - Tarik dana
    7️⃣ /referral - Kode referral
    8️⃣ /help - Bantuan
    
    💼 CWPay - Investasi Digital Terpercaya

✅ Kalau bot balas, berarti BERHASIL! 🎉

┌──────────────────────────────────────────────────────────────────────┐
│  KALAU BOT TERPUTUS / ERROR                                          │
└──────────────────────────────────────────────────────────────────────┘

1. Buka: http://localhost:3000/bot-admin.html
2. Klik tombol "🔄 Restart Bot"
3. Tunggu QR Code muncul (kalau session expired)
4. Scan ulang kalau perlu

ATAU

Restart server:
   Ctrl+C (stop server)
   npm start (jalankan lagi)
