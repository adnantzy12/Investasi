🚀 CARA MENJALANKAN (3 LANGKAH MUDAH):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INSTALL DEPENDENCIES
    
    npm install


2️⃣  JALANKAN SERVER
    
    npm start
    
    (Server akan berjalan di http://localhost:3000)


3️⃣  BUKA HALAMAN ADMIN & SCAN QR
    
    • Buka browser: http://localhost:3000/bot-admin.html
    • Tunggu QR Code muncul
    • Buka WhatsApp di HP → Menu → Linked Devices
    • Tap "Link a Device" → Scan QR Code
    • Selesai! Bot siap digunakan ✅

Android:

iPhone:
  WhatsApp → Settings → Linked Devices → Link a Device → Scan
