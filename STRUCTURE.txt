🚀 FLOW KERJA:

1. User jalankan: npm start
2. Server berjalan di port 3000
3. WhatsApp client initialize
4. QR code di-generate
5. QR code dikirim via Socket.IO ke bot-admin.html
6. Admin scan QR code dari WhatsApp
7. Bot terhubung & siap menerima pesan
8. Session tersimpan di whatsapp-session/
9. Restart server → bot langsung connect (tidak perlu scan lagi)

📊 TEKNOLOGI YANG DIGUNAKAN:

Backend:
  • Node.js + Express.js
  • whatsapp-web.js (WhatsApp Web API)
  • Socket.IO (real-time communication)
  • Puppeteer (headless browser untuk WhatsApp Web)
  • bcryptjs (password hashing)
  • jsonwebtoken (JWT authentication)

Frontend:
  • HTML5 + CSS3
  • Vanilla JavaScript
  • Socket.IO Client
  • Responsive design
